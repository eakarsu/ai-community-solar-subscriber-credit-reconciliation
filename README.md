# Community Solar Subscriber Credit Reconciliation

Reconcile utility bill credits and subscriber fees to project production, allocation percentages, and program tariffs.

**Primary buyer:** Community solar developers and subscriber managers. **Evidence:** program tariffs, projects, subscribers, allocations, meter production, utility bill credits, subscription fees, low-income incentives, statements, and cash.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Program tariff library
- Project subscriber registry
- Subscription allocation control
- Meter production ingestion
- Utility allocation file
- Bill credit calculation
- Low-income adder
- Subscription fee calculation
- Subscriber move handling
- Unallocated production
- Utility statement matching
- Subscriber invoice reconciliation
- Utility dispute workflow
- Cash reconciliation
- Project subscriber analytics

Run `./start.sh`, then open <http://127.0.0.1:4715>. API: `5715`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
